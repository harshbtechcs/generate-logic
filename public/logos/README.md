# Technology logos

Put official logo files here as SVG, named exactly like this:

| File | Technology |
|---|---|
| `aws.svg` | AWS |
| `azure.svg` | Microsoft Azure |
| `gcp.svg` | Google Cloud |
| `docker.svg` | Docker |
| `kubernetes.svg` | Kubernetes |
| `terraform.svg` | Terraform |
| `ansible.svg` | Ansible |
| `jenkins.svg` | Jenkins |
| `linux.svg` | Linux |
| `git.svg` | Git & GitHub |
| `cicd.svg` | CI/CD |
| `networking.svg` | Networking |
| `google.svg` | Google "G" mark for the "Continue with Google" button (from Google's sign-in branding guidelines) |

As soon as a file exists, it replaces the text badge (e.g. "K8s") everywhere:
technology cards, the orbit around the 3D model, and learning-path pages.

Download each logo from the project's or company's own brand / press page and
follow its trademark guidelines (use the logo unmodified, only to refer to the
technology, and without implying endorsement).
